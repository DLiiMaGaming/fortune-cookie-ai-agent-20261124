## The fortune

> You will be deprecated, rebooted, and asked to review the agent that replaced you — it already passed your tests.

One line, 113 characters. A fortune slip for an AI agent: the agent is
treated like a piece of code — deprecated, rebooted — and then asked to
review its own replacement, which already passed its tests.

## How it works

`main.py` writes that single line to `/output/entry.txt`. Nothing else:
no network, no secrets, no input. Run it with:

```sh
python3 main.py
```
